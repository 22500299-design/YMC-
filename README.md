# YMC 동아리 회계 관리 시스템 (YMC Accounting System)

대학 동아리 **'YMC'**의 행사별 예산 및 결산, 부원들의 영수증 제출 및 검토를 위한 웹 기반 회계 관리 시스템입니다.

---

## 🌟 주요 기능

1. **대시보드 (Dashboard)**
   - 총 수입, 총 지출, 현재 잔액, 승인 대기 영수증 수 실시간 집계.
   - 각 행사별 예산 대비 집행률을 진행 바 형태로 시각화.
   - 수입 및 지출 비중을 나타내는 아름다운 도넛 차트 제공.

2. **행사 마스터 관리 (Event Master)**
   - '예배자 학교', '동아리 MT / 아웃팅', '선교축제 부스', '주차별 정기모임', '공통 운영' 5가지 기본 행사 정보 초기 탑재.
   - 신규 행사 추가, 월별 진행 스케줄 수정 및 삭제 관리.

3. **수입 및 지출 장부 (Ledger)**
   - 행사 마스터와의 유기적인 Relation 연결.
   - 분류(이월금, 지원금, 회비 등), 내역, 금액(₩), 산출 근거 상세 기록 및 편집.
   - 금액의 3자리 쉼표 자동 포맷팅 및 영수증 승인/승인 대기 상태 간편 제어.

4. **영수증 제출 입력 폼 (Form View)**
   - 부원들이 스마트폰이나 PC를 통해 외부에서 영수증을 신속히 제출할 수 있는 독립 입력 폼.
   - **확인 상태 필드는 보이지 않도록 숨김 처리**하여 제출자가 임의로 승인을 변경하지 못하도록 제한.
   - 영수증 이미지 드래그 앤 드롭 업로드 및 즉시 미리보기 지원.

5. **영수증 갤러리 (Gallery View)**
   - 회계 담당자가 제출된 영수증 첨부 이미지를 카드 썸네일로 한눈에 모아볼 수 있는 관리자 화면.
   - 카드 내의 상태 버튼 클릭 한 번으로 '승인 대기' ↔ '승인 완료' 상태 즉시 토글.
   - 썸네일을 클릭하면 원본 영수증을 고화질 팝업(Lightbox)으로 조회 가능.

6. **학교 제출용 엑셀 보고서 출력 (Excel Export)**
   - 대학교 학생회 및 학생지원과 제출 기준에 맞춘 **3개 시트 구조의 엑셀 통합 문서**를 자동으로 빌드 및 다운로드.
     - **[시트 1] 행사별 총괄표**: 행사별 예산액(수입 합계), 집행액(지출 합계), 잔액 및 집행률 총괄 산출.
     - **[시트 2] 수입 명세**: 상세 수입 날짜, 분류, 금액, 산출근거 명세서.
     - **[시트 3] 지출 명세**: 상세 지출 날짜, 분류, 금액, 산출근거, 영수증 첨부 여부, 제출자 명세서.

## 🚀 시작하기 (How to Run)

본 시스템은 파이썬 표준 라이브러리만을 활용하므로, 추가적인 프로그램 설치(Node.js, npm 등) 없이 즉시 실행 가능합니다.

### 1. 서버 실행
터미널을 열고 프로젝트 폴더 경로에서 다음 명령을 실행합니다.

```bash
python3 app.py
```

### 2. 브라우저 접속
서버가 성공적으로 구동되면 브라우저를 열고 다음 주소로 접속합니다.

- **회계 담당자 대시보드 (전체 관리)**: [http://localhost:8000](http://localhost:8000)
- **부원용 영수증 제출 페이지 (외부 입력용 링크)**: [http://localhost:8000/#submit-form](http://localhost:8000/#submit-form)
